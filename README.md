# Scoop bucket

Scoop manifests for [claude-sessions-sync](https://github.com/ashiqfardus/claude-sessions-sync),
which backs up Claude Code conversations to a synced folder and resumes them on another
computer.

```powershell
scoop bucket add ashiqfardus https://github.com/ashiqfardus/scoop-bucket
scoop install ashiqfardus/claude-sessions
```

The manifests are written by GoReleaser on each release. Do not edit them by hand.
